# mooc-java-programming-ii

This repository contains the **second part** of the Java programming exercises from the online course hosted at [https://java-programming.mooc.fi/](https://java-programming.mooc.fi/).

> ⚠️ **Note:** The solutions included in this workspace are meant for **comparison and learning purposes only**. They should **not** be treated as the canonical or "right" answers. There are many valid ways to solve each exercise, and learners are encouraged to explore alternative implementations.

## Repository Structure

- Each exercise is located in a separate subfolder named `partXX-PartXX_YY.<ExerciseName>`.
- This workspace contains all of **Part 2** of the course, covering chapters **08 through 14**:
  - **part08** – ArrayLists, HashMaps, and other collections
  - **part09** – Object-oriented programming: inheritance, abstract classes, and interfaces
  - **part10** – Comparable, generics, reading files, regular expressions, and enums
  - **part11** – Class diagrams, packages, exception handling, and object serialization
  - **part12** – Enumerated types, generics, and working with arrays
  - **part13** – Graphical user interfaces with JavaFX
  - **part14** – Graphics, animation, and simple games/database use with JavaFX
- Part 1 (chapters 1–7) is maintained in a separate repository: [mooc-java-programming-i](https://github.com/SylvesterNdwata/mooc-java-programming-i).

## Important

- This repository is an **educational companion** for the MOOC course. It tracks progress through Part 2.
- Do **not** assume that any single solution here is the only way; many problems have multiple correct approaches.
